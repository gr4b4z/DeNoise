# Architecture Decision Records

The accepted ADRs (1–14) are in [`../03-architecture-and-adrs.md`](../03-architecture-and-adrs.md).

that introduces them (AGENTS.md §5 rule 14). Milestone-level "Decisions made" lists live in `../milestones/`.
