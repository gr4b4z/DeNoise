## Decisions made

- **Seed active.** A new Azure/Atlas integration interprets events immediately; the wizard edits by creating version 2. Better a `unknown` environment than a quarantine queue on day one.
- **Preview is synchronous, replay is a job.** Preview never touches state and answers in one request; retry and historical can span thousands of events and report through `ops.job.result`.
- **A failed probe degrades, a successful one proves nothing.** Reachability of the Admin API says nothing about alert evaluation; only the canary or a bound heartbeat raise coverage.
- **Credentials inside `capabilities`.** Atlas keys are encrypted with the same protector as destination secrets and stored in the JSON document rather than a new column; `Describe` exposes group id and base URL only.
- **Header capture.** The signature header is checked even when it is not in `Limits:StoredHeaders`; stored headers stay the allow-listed set.
