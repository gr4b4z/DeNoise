## Decisions made

- **One grouping document, like routing.** Rules are evaluated in order; the first match groups. A key field without a value does not group (an ambiguous key would merge unrelated conditions).
- **Grouping never closes members.** Closing the window only stops adoption; spec §16.3 "closing one child does not close others" and "never claims a shared root cause".
- **Windows apply to existing episodes at start**, not only to new ones — otherwise a maintenance window declared for a noisy hour would still deliver everything that was already open.
- **Muted rows are coalesced, not sent late.** The end summary is the current truth; replaying stale notifications would be exactly the noise the window was meant to avoid.
- **A per-episode silence survives a window end.** Only the window's own scope is released; an operator's explicit silence on one episode keeps its own `until`.
- **Two connections per in-flight normalise.** The transition hook reads policies and windows on the scoped read side while the processing transaction holds its own connection; pools must be sized for twice the worker concurrency (the test fixture now uses 16 for 8 concurrent workers).
